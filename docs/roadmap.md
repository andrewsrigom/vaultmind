# Roadmap

VaultMind is useful today as a self-hosted knowledge vault. The roadmap stays close to its ingestion, retrieval, and citation loop.

## Next

- Add a documented backup and restore command for PostgreSQL and the connector-encryption key.
- Package a reproducible container image for the application.
- Add a reverse-proxy deployment example with TLS and health checks.
- Improve Notion and Google Drive fixture coverage.
- Add reindex tooling for embedding-model changes.
- Polish the first-run path when no sources exist.

## Later

- Support another model provider behind the existing interfaces.
- Add export and import for personal vault data.
- Improve retrieval evaluation and citation quality reporting.
- Add a small source-adapter plugin contract after a second external contributor needs it.

A feature belongs in the roadmap only when it strengthens source ingestion, retrieval quality, citation review, or safe operation.
