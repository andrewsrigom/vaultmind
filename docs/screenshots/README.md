# Screenshots

Screenshots in this directory use synthetic or intentionally public documents.

Before replacing one:

- verify that no private source names, paths, prompts, or answers are visible;
- hide browser extensions, account avatars, tokens, and local file paths;
- use the default theme and a reproducible viewport;
- confirm that the pictured flow still exists in the current application.

The root README uses `chat-answer.png` as the main project preview.
