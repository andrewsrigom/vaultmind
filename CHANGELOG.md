# Changelog

## 0.1.0 - 2026-08-24

Initial public release.

### Added

- Multi-source ingestion for GitHub, Notion, Google Drive, and VaultMind documents.
- Markdown-aware chunking, OpenAI embeddings, and pgvector retrieval.
- Ask AI with saved conversations, source excerpts, and citations.
- Spaces, local document authoring, articles, and knowledge-area discovery.
- Read-only indexed search over a local MCP stdio server.
- Optional password protection for the web interface.
- A deterministic demo with synthetic data and no external API calls.
- Local setup, architecture, security, contribution, and RAG documentation.
